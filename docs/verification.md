# Проверка выпуска 2026-10-12

- Сборка TypeScript и Vite завершилась успешно.
- npm audit: уязвимостей не обнаружено.
- На домашнем сервере пройдены 33 проверки на настоящих PostgreSQL и Redis в отдельной базе taskmaster_test.
- Проверены создание и изменение задач, версии и конкурирующие изменения, доступ к чужим данным, приглашения, статусы, спринты, таймеры, файлы, комментарии, чек-листы, уведомления и их повторы, подпись и повторная доставка GitHub.
- Сценарий aiogram проверяет регистрацию, создание проекта, подтверждение задачи, повтор кнопки и изменение приоритета через Telegram updates с тестовым транспортом.
- В браузере через настоящий API созданы проект и задача, добавлены комментарий и пункт чек-листа, запущен таймер, задача перемещена в In Progress перетаскиванием.
- Перезапуск тестового backend сохранил ID таймера и исходное время старта, накопленное время продолжило увеличиваться.
- Проверены мобильная ширина 390 px, светлая и тёмная темы. HTTPS /health отвечает ok. API, bot, worker, PostgreSQL и Redis имеют healthy status. Бот запускает Telegram polling и устанавливает команды и кнопку меню.
- Для Telegram используется существующий HTTP-прокси сервера, поскольку прямой выход из Docker недоступен. Фоновая доставка работает без загрузки полного aiogram SDK для уменьшения потребления памяти.
- Секреты и приватные ключи проверены перед публикацией. .env, архивы, результаты тестов и пользовательские вложения исключены из Git.

Подключение личных GitHub-репозиториев и создание webhook требует указать конкретный репозиторий в настройках проекта. Этот внешний шаг не выполнен за пользователя. Проверка браузера использует тестовую Telegram-оболочку и настоящую серверную проверку подписи; окончательный вход с реального телефона выполняется через кнопку меню бота.
