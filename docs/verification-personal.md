# Проверка личного диспетчера

- Пройдены 62 проверки на PostgreSQL и Redis в отдельной тестовой базе.
- Проверены обычный текст, русские сроки, даты словами, несколько неоднозначных дат, приватность, конфликтующие изменения и атомарное сохранение дела вместе с напоминанием.
- Проверены разовое уведомление, повтор каждый час, каждый день, каждые 3 дня и каждую неделю, восстановление очереди, повтор при недоступности Telegram и отключение после выполнения.
- Сценарий Telegram проверяет добавление без проекта, повтор одного сообщения, выбор времени и частоты, голосовое, подтверждение расшифровки и повторные нажатия.
- Миграция с 0001 до 0002 проверена на задаче с автором и исполнителем. Исходная задача сохранена, оба участника получили личную копию, посторонний пользователь её не получил. Alembic check не нашёл расхождений схемы.
- Локальный Vosk на домашнем сервере распознал синтезированную русскую фразу «Через неделю нужно сдать проект по высшей математике» без ошибки. Обработка записи заняла около 10 секунд. Это проверка тестовой записи, качество реальных голосовых зависит от звука и формулировки.
- В мобильном браузере через настоящий API добавлено дело, задан срок через неделю, сохранено ежедневное напоминание за день до срока в 09:00, дело выполнено и повтор отключён. Ошибок в консоли нет.
- Голосовые не передаются внешнему сервису распознавания. Временные аудиофайлы не попадают в Git. HTTP-клиент не записывает URL с токеном бота в журнал.

Обновление сохраняет прежние данные и включает отдельный процесс распознавания. Перед миграцией сделана резервная копия базы и исходников. Новые настройки времени относятся к часовому поясу Europe/Moscow.
